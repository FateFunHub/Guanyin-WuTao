# 大觀音亭暨祀典興濟宮 數位寺廟導覽殿堂 (Da Guanyin Ting & Xingji Temple Guide)

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-brightgreen)](https://fatefunhub.github.io/Guanyin-WuTao/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

「大觀音亭暨祀典興濟宮」數位文化導覽系統，是專為臺南直轄市定古蹟——**大觀音亭**（明鄭永曆32年，1678年創立）與**祀典興濟宮**（明鄭永曆33年，1679年創立）量身設計的沉浸式線上數位導覽平台。

本系統呈現全臺獨一無二的**「佛道雙廟並立、中介官廳相連」**珍貴格局，將慈航普渡的**觀音佛祖**、妙手回春的醫神**保生大帝**、府城名聞遐邇的**闊嘴月老**，以及超人氣**愛吃炸雞的下壇虎爺將軍**生動展示，並結合即時 **QR Code 現場立牌生成**與**真人語音導覽**。

---

## 🌟 核心古蹟與文化亮點

### 1. 🏛️ 建築與國寶級文物
- **全臺孤例 ‧ 中介「官廳」**：清代文武官員前來興濟宮主持春秋官方祀典時之更衣、齋宿與休憩場所，為全臺寺廟罕見之官祀遺構。
- **國寶名師陳壽彝彩繪門神**：薪傳獎大師以細緻金線（泥金勾勒）描繪秦叔寶與尉遲恭，威武傳神。
- **大觀音亭淺浮雕花瓶木門**：佛門不繪門神，以典雅淺浮雕花瓶插四季花卉，寓意「四季平安、富貴吉祥」。
- **雙廟三川殿燕尾脊剪黏**：閩南硬山翹脊，屋脊雙龍搶珠與福祿壽三仙剪瓷嵌彩。
- **八角如意藻井**：無釘榫卯大木作極致，層層旋轉如蜘蛛結網，兼具力學抗震與天圓地方哲理。
- **百年保生藥籤文化**：珍藏內科、外科、眼科、小兒科四大藥籤櫃與同治、光緒年間名宦古匾。

### 2. 🙏 核心神尊與特色信仰
- **觀音佛祖 (大觀音亭)**：臺疆觀音開基名剎，慈航普渡、手持甘露淨瓶，滌淨世人煩惱憂慮。
- **保生大帝 (祀典興濟宮)**：俗稱「頂大道公」，全臺唯一列入官方祀典之保生大帝廟，醫神吳真人懸壺濟世。
- **闊嘴月老 (大觀音亭)**：名列府城四大月老，嘴大善於言媒說合、側耳專心傾聽單身男女祈願，牽紅線極度靈驗。
- **下壇黑虎將軍 (興濟宮)**：人氣爆棚的「愛吃炸雞虎爺」，造型圓潤古錐，專治小孩腮腺炎（豬頭皮）、招財咬錢水。
- **江仙官與張聖者**：保生大帝得力副將，一持藥壺調配金丹、一持法劍斬除疫癘。
- **註生娘娘與十二婆姐**：專司求子受孕、換花安胎保產與幼童平安。

### 3. 📱 智慧 QR Code 互動中心
- **各展區與神尊專屬 QRCode**：一鍵產生並切換「雙廟總導覽」、「官廳古蹟」、「保生大帝專牌」、「觀音佛祖專牌」、「闊嘴月老專牌」、「炸雞虎爺專牌」與「參拜動線」。
- **一鍵列印實體現場導覽立牌**：具備精美 `@media print` 列印樣式，廟方可直接印出貼於神桌旁。
- **高解析度 PNG 下載**：隨時儲存 QR Code 圖檔印製文宣或紀念品。
- **自訂網址產生器**：輸入任意網址或展區錨點立即生成。

### 4. 🔊 真人語音導覽 (Web Speech API)
- 各建築特色與神尊卡片皆支援中文真人發音解說，方便現場長者與觀光客邊看邊聽。

### 5. 🚶 雙廟五步參拜動線與線上保生靈籤
- 依序導引：天公爐 ➔ 興濟宮保生大帝 ➔ 下壇虎爺將軍 ➔ 大觀音亭觀音佛祖 ➔ 闊嘴月老。
- 內建**「保生藥籤與線上祈願」**擲筊抽籤互動，帶給信眾心靈療癒與吉慶指引。
