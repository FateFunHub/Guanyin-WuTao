# 觀音武道 數位寺廟導覽殿堂 (Guanyin-WuTao Temple Guide)

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-brightgreen)](https://fatefunhub.github.io/Guanyin-WuTao/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

「觀音武道」是一套現代化、響應式且兼具東方廟宇禪意美學的**寺廟數位文化與導覽系統**。
專為傳統信仰、古蹟建築與信眾參拜體驗量身打造，將寺廟深厚的建築工藝美學與神明文化透過數位介面生動呈現，並整合了即時 **QR Code 導覽牌生成與列印** 以及 **真人語音解說**。

---

## 🌟 核心功能特色

### 1. 🏛️ 六大建築工藝美學專題
- **三川殿與燕尾脊**：開三門迎祥納福，大鳥展翅之閩南雙曲燕尾翹脊。
- **八角藻井與如意斗栱**：無釘榫卯大木作巔峰，抗震與天圓地方之八卦漩渦象徵。
- **雙龍剪黏與交趾陶**：嵌瓷雙龍搶珠與低溫釉燒歷史演義壁堵。
- **八角透雕盤龍石柱**：泉州青斗石精雕，升龍降龍乘風破浪之石作極致。
- **丹墀御路龍陛與抱鼓石**：神明御道中軸與抱鼓鎮山門之威嚴雕飾。
- **精雕雀替與員光花鳥**：插角分擔橫樑重壓，結合鳳凰仙禽之吉祥寓意。

### 2. 🙏 供奉神明與虔誠信仰
- **觀世音菩薩**：主殿大士，持甘露淨瓶，大慈大悲尋聲救苦。
- **關聖帝君 (武聖)**：協天大帝，浩然正氣、忠義千秋與商賈武財神。
- **天上聖母 媽祖**：天后慈憫，出外打拼與行車交通平安護祐。
- **文昌帝君**：文曲星曜，開啟智慧心燈，金榜題名與事業升遷。
- **註生娘娘**：生育保幼，添丁賜嗣與安胎撫育。
- **下壇黑虎將軍**：神案辟邪除凶，換虎爺錢水、咬錢招財與幼童守護神。

### 3. 📱 智慧 QR Code 互動中心
- **各區專屬 QR Code**：一鍵切換全館、建築、諸神、各神尊與參拜路線的專屬二維碼。
- **現場實體導覽立牌輸出**：內建一鍵列印功能，廟方或志工可直接列印標準尺寸之現場神案導覽牌。
- **高清圖片下載**：支援將生成的 QR Code 下載為高解析度 PNG 檔案。
- **自訂網址產生器**：輸入任意網址或展區錨點即可動態產生。

### 4. 🔊 真人語音導覽 (Web Speech API)
- 各建築點與神尊卡片皆具備「語音導覽」按鈕，長者與訪客在現場免看小字，點擊即聽專業國語語音朗讀。

### 5. 🚶 五步參拜動線與線上靈籤
- 清楚圖解天公爐、主殿、武聖殿、偏殿至虎爺將軍的標準參香流程。
- 內建線上擲筊求籤互動，為信眾提供心靈指引與吉祥解析。

## 🚀 部署與線上啟用 (GitHub Pages)

本專案完全基於純靜態前端技術構建，可直接透過 GitHub Pages 免費發布：

1. 進入 GitHub 倉庫設定頁面：`Settings` -> `Pages`
2. 在 **Branch** 選取 `main` 分支與根目錄 `/ (root)`，點擊 **Save**。
3. 數十秒後即可獲得線上正式公開網址：  
   👉 **`https://fatefunhub.github.io/Guanyin-WuTao/`**
